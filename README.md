**Assistente financeiro inteligente via WhatsApp**

Projeto pessoal de uma solução de IA voltada para **organização e gestão financeira pessoal através de conversas no WhatsApp**.

A ideia é reduzir a complexidade de controlar as finanças, permitindo que o usuário registre informações e consulte seus dados utilizando linguagem natural.

**Tecnologias:** Python · FastAPI · PostgreSQL · Supabase · Google Gemini · WhatsApp · Stripe

**Plataforma de estudos para o ENEM**

Projeto voltado para personalização do processo de estudo, acompanhando o progresso diário do usuário e utilizando IA para gerar análises sobre seu desempenho.
